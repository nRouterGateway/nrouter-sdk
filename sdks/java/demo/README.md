# nRouter Java SDK Demos & Examples

Runnable demonstrations for the official nRouter Java SDK (`ai.nrouter:nrouter-sdk`).

## Prerequisites

```bash
export NROUTER_API_KEY="sk-nrouter-..."
```

## Available Demos

- `quickstart.java`: Quickstart utilizing `NRouter` client, model discovery, chat completions, cost headers, and error classification.

## Running

```bash
javac -cp "../target/*:." quickstart.java
java -cp "../target/*:." quickstart
```
