# nRouter Swift SDK Demos & Examples

Runnable demonstrations for the nRouter Swift SDK (`NRouter`).

## Prerequisites

```bash
export NROUTER_API_KEY="sk-nrouter-..."
```

## Available Demos

- `quickstart.swift`: Async/await quickstart demonstrating NRouter initialization, chat completions, streaming, and metadata tracking.

## Running

```bash
swift quickstart.swift
```
