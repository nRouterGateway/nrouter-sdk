# nRouter Dart SDK Demos & Examples

Runnable demonstrations for the nRouter Dart & Flutter SDK (`nrouter`).

## Prerequisites

```bash
export NROUTER_API_KEY="sk-nrouter-..."
dart pub get
```

## Available Demos

- `quickstart.dart`: Quickstart demonstrating synchronous/async completions and metadata inspection.
- `nrouter_example.dart`: Complete Flutter/Dart console example.

## Running

```bash
dart run quickstart.dart
dart run nrouter_example.dart
```
