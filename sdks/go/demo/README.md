# nRouter Go SDK Demos & Examples

Runnable demonstrations for the nRouter Go SDK (`github.com/nRouterGateway/nrouter-sdk/sdks/go/v3`).

## Prerequisites

```bash
export NROUTER_API_KEY="sk-nrouter-..."
```

## Available Demos

- `quickstart.go`: Quickstart showcasing completions, token tracking, and typed errors.
- `stream/stream_example.go`: Token streaming with channels and context cancellation.

## Running

```bash
go run quickstart.go
go run stream/stream_example.go
```
