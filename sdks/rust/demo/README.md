# nRouter Rust SDK Demos & Examples

Runnable demonstrations for the nRouter Rust SDK (`nrouter`).

## Prerequisites

```bash
export NROUTER_API_KEY="sk-nrouter-..."
```

## Available Demos

- `quickstart.rs`: Async Tokio quickstart demonstrating client builder, chat completion, cost metadata extraction, and typed error handling.

## Running

```bash
cargo run --example quickstart
```
