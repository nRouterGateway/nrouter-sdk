# @nrouter_ai/video-prompt-generator

Turns a short idea into a production-ready video brief for a specific AI video tool. The brief is
generated by a model called through [nRouter](https://nrouter.ai) with
[`@nrouter_ai/sdk`](https://www.npmjs.com/package/@nrouter_ai/sdk). The package only writes the
prompt; it does not open, control, render or publish anything in a third-party video tool.

## Install

```bash
npm install @nrouter_ai/video-prompt-generator
```

Requires Node.js 22.18 or later and an nRouter API key (`sk-nrouter-...`).

## Usage

```ts
import { generateVideoPrompt } from '@nrouter_ai/video-prompt-generator';

const brief = await generateVideoPrompt({
  query: 'A cinematic 10-second introduction of the nRouter dashboard',
  videoModel: 'Google Veo',
});
console.log(brief);
```

Each call sends one billed request to `POST /v1/messages` through `client.nr.messages(...)`. The
system prompt is built from the packaged skill files: `skills/instructions.md`,
`skills/brand.md` and the guide for the selected video model in `skills/models/`. The return value
is the text of the reply (multiple text blocks are joined with a blank line).

A runnable example is in [`examples/basic.ts`](examples/basic.ts).

## Options

| Option | Type | Default | Notes |
|---|---|---|---|
| `query` | `string` | required | Non-empty after trimming; at most `MAX_QUERY_LENGTH` (8000) characters. |
| `videoModel` | `string` | required | One of the guides in `skills/models/`, see below. |
| `model` | `string` | `NROUTER_MODEL`, then `DEFAULT_MODEL` (`claude-haiku-4-5-20251001`) | nRouter model id that writes the brief. A blank `NROUTER_MODEL` counts as unset. |
| `maxTokens` | `number` | `DEFAULT_MAX_TOKENS` (1024) | Positive integer, sent as `max_tokens`. |
| `apiKey` | `string` | `NROUTER_API_KEY` | Passed to `new nRouter({ apiKey })`; the SDK reads the env var when omitted. |
| `conversation` | `{ role: 'user' \| 'assistant'; content: string }[]` | `[]` | Earlier turns, oldest first; at most 50. `query` is sent after them. |

### Video models

`videoModel` is matched against the files in `skills/models/` by slug or by the human name in
each guide's heading. Case, spaces and punctuation are ignored, so `Google Veo`, `google-veo` and
`googleveo` are the same.

| Slug | Name |
|---|---|
| `google-veo` | Google Veo |
| `luma-dream-machine` | Luma Dream Machine |
| `runway-gen3` | Runway Gen-3 |
| `sora` | OpenAI Sora |

`listVideoModels()` returns this list at runtime. Any other value is rejected before a request is
sent.

### Testing without the network

`generateVideoPrompt(options, deps)` accepts `deps.client`, any object with the same
`nr.messages(body)` method as the real `nRouter` client (`MessagesClient`). When it is given, no
client is constructed and `apiKey` is ignored.

```ts
const client = {
  nr: {
    messages: async () => ({ body: { content: [{ type: 'text', text: 'Shot Summary: ...' }] } }),
  },
};
await generateVideoPrompt({ query: 'Dashboard intro', videoModel: 'sora' }, { client });
```

## Errors

| Error | When |
|---|---|
| `VideoPromptValidationError` | Invalid input, before anything is sent. `field` is `query`, `videoModel`, `model`, `maxTokens` or `conversation`. An unknown `videoModel` lists the allowed values in the message. |
| `VideoPromptResponseError` | The reply contained no non-empty text block. `requestId` carries the gateway request id when present. |
| `nRouterError` and subclasses from `@nrouter_ai/sdk` | Missing or malformed API key, gateway refusals (auth, credit, rate limit, guardrail), transport failures. Re-thrown unchanged. |

Both package errors extend `VideoPromptError`. No error raised by this package includes the API
key.

## Customising the skills

The prompt guidance lives in markdown under `skills/` and ships with the package (it is listed in
`files`), so behaviour can be tuned without changing code:

- `skills/instructions.md` — role, output structure and tool-specific terminology.
- `skills/brand.md` — nRouter brand and video delivery rules.
- `skills/models/<slug>.md` — one guide per video model. Adding a file adds an accepted
  `videoModel`; its first line should be `## <Name> Prompt Architecture` so the human name can be
  matched.
- `skills/references/` — a reference screenshot of nrouter.ai for people writing or reviewing
  briefs. It is shipped but not sent to the model.

The files are read relative to the compiled module, so they resolve from `dist/` when the package is
installed from npm.
